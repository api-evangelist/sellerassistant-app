Seller Assistant provides Amazon seller software for wholesale, online arbitrage, and agency workflows. The platform offers tools such as a repricer, profitability analyzer, price‑list analyzer, lister, AI supplier finder, brand analyzer, bulk restriction checker, and a full API/MCP server for integration. Founded by Linen Art, LLC, it serves sellers looking to automate and optimize their Amazon business across multiple channels.

**Areas:** Company · Amazon · E‑commerce · SaaS · Automation · Wholesale

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Seller Assistant: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
